# Spaced Repetition Plan

The goal is **retrieval practice**: try to remember a method or property before looking it up.

## Review intervals

For each completed problem:

- **Day 0:** solve it and explain the key operator/method.
- **Day 1:** solve it again without notes.
- **Day 3:** solve it from a blank editor.
- **Day 7:** solve a small variation.
- **Day 14:** explain why the method/operator works.
- **Day 30:** complete it as part of a mixed review.

If you cannot recall the feature, review it and schedule another short retrieval attempt.

## Especially important: `||` vs `??`

- `||` falls back for **any falsy value**, including `''` and `0`.
- `??` falls back only for **`null` or `undefined`**.

Problems 56–57 and 86–87 deliberately reinforce this distinction because it is common in JavaScript configuration and test automation code.
