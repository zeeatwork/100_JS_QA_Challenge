# Version 2 Plan: Problems 50-100

Problems 01-49 stay as written. Version 2 rewrites Problems 50-100 in batches of 10 on the `v2-problems-50-100` branch. Each batch is merged when it's finished.

## What changes in v2

- **Drills for repetition.** Some problems are single-method drills: one method, three short reps in different QA situations. Drills name the method on purpose, because repetition is the point.
- **Problems hide the concept.** Regular problems describe the QA task and leave you to recognize which JavaScript feature fits.
- **More tests and edge cases.** Every function has several assertions, including the cases that tend to break real test code (empty strings, `0`, `null`, short input).
- **Difficulty increases by batch.** Early batches are drills. Later batches combine skills, then add ambiguity where you need to question the requirement and write some of your own tests.
- **Assistance ladder.** Problem, attempt, optional hint, debugger, docs, then the reference solution last.
